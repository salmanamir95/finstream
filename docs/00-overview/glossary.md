# Glossary

| Term | Meaning |
|---|---|
| Account | A financial account record owned conceptually by a customer. |
| Current account | Account variant with an overdraft limit. |
| Savings account | Account variant with an interest rate. |
| Overdraft | Approved amount by which a current account may go below its balance; balance handling is not implemented. |
| Interest rate | Rate stored for a savings account; interest calculation is not implemented. |
| DTO | Object used to exchange data at the API boundary. |
| Entity | Object persisted by JPA/Hibernate. |
| Idempotency | Repeating a request has the same business effect as sending it once. |
| Outbox | A durable event record written with business data, then published asynchronously. |
| Saga | Coordinated sequence of local transactions across services. |
