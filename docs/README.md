# FinStream documentation

This package documents the repository as inspected on 1 September 2026. Its status labels are deliberate:

- **Confirmed** — present in source/configuration.
- **Inferred** — a reasonable conclusion from the implementation.
- **Proposed** — a recommendation, not an implemented feature.
- **Unknown** — requires product or operational confirmation.

Start with [Executive summary](00-overview/executive-summary.md), then [Architecture overview](02-architecture/architecture-overview.md) and [Account API](05-api/account-api.md). Client-oriented material is in [`client-docs/`](../client-docs/).

The existing `readme.md` and `docs/microservices.md` describe a broader event-driven target. They are not evidence that those services are implemented; this package records the current repository as the source of truth.
