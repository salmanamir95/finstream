# Client glossary

| Term | Plain-language meaning |
|---|---|
| Account | A record representing a financial account. |
| Current account | Account with an overdraft setting. |
| Savings account | Account with an interest-rate setting. |
| API | A documented way for systems to communicate. |
| Authentication | Proving who is calling. |
| Authorisation | Deciding what a caller may do. |
| Idempotency | Safely repeating a request without duplicate effect. |
