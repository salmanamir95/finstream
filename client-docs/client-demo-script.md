# Client demonstration script

1. Explain the need for a consistent account-management foundation and the current scope.
2. Create a current account, retrieve it, and show an overdraft-limit update.
3. Create a savings account, retrieve it, and show an interest-rate update.
4. Demonstrate an invalid specialised value and explain the current error-contract limitation.
5. Show the high-level solution view and distinguish delivered capability from planned identity, transactions, audit, and event integration.
6. Close with production-readiness gaps: access control, validation, testing, observability, and operating commitments.
